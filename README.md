# Atmosoft Foundation

Powering modern digital experiences with a lightweight Next.js + Tailwind starter and reusable UI primitives for marketing sites and product landing pages.

## What this is
Atmosoft Foundation is a Next.js-based frontend scaffold and component foundation tailored for marketing and product pages. It provides a responsive layout, header/footer components, a styled home page (hero, features, projects, CTA), and a small UI kit to accelerate building company/product websites.

### Stack
- Language(s): TypeScript (primary), JavaScript
- Framework / runtime: Next.js 15 (App Router) + React 19
- Notable libraries:
  - Tailwind CSS (styling & utilities)
  - Radix UI (accessibile primitives)
  - lucide-react (icons)
  - react-hook-form + zod (forms & validation)
  - sonner (toasts/notifications)
